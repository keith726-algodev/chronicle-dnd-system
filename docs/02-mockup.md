## What it shows

- All five screens from the proposal (Home, Category Branch View, Entry Viewer/Editor, New Category and Segment Composer, Settings) and no others
- Real content from the sample world (Orcs, Culture & Rites, Tradines Hecate), not placeholder text
- Two empty states: a brand-new library and a brand-new category

## Honest note

These images are renders of the built client running in demo mode, with the design-system tokens and gradients applied, and not a separate design-tool file. So they match the app by construction. Two things were added to the app while producing them: the empty-state messages on Home and Branch View, which did not exist before. The demo-mode banner is hidden in the renders so the screens show the interface itself.
